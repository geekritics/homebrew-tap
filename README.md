# Homebrew Potar

[Potar](https://potar.app) — per-app audio router for macOS: send each app's sound to the
output you choose (headphones, speakers, AirPods…), at the same time, with per-app volume.

```sh
brew install --cask geekritics/tap/potar
```

Potar updates itself (Sparkle); Homebrew is only needed to install it.
